# Point d'information : lunettes et autres produits intégrant une fonction d'amplification auditive

Page web du point d'information de l'Ordre des audioprothésistes du Québec aux opticiens d'ordonnances et aux optométristes, daté du 13 novembre 2026. Publiée par Cloudflare Pages (compte de l'Ordre) à chaque poussée sur `main`.

Ne pas modifier ces fichiers à la main. Ils sont produits par `scripts/point_info_lunettes_html.py` du générateur des formulaires de l'Ordre (`Projets/Dépistage/Formulaires-generateur`), qui produit aussi le PDF à partir du même texte (`point_info_lunettes_contenu.py`).

- Sur un ordinateur, la page légale s'affiche telle quelle.
- À l'impression, elle sort sur une page au format légal.
- Sur un téléphone, elle s'affiche en une colonne.
